# Triage 标签

工程技能使用五种标准 triage 角色。下表将这些角色映射到本仓库问题跟踪系统中的实际标签。

| mattpocock/skills 中的角色 | 本仓库标签        | 含义                         |
| -------------------------- | ----------------- | ---------------------------- |
| `needs-triage`             | `needs-triage`    | 等待维护者评估               |
| `needs-info`               | `needs-info`      | 等待报告者提供更多信息       |
| `ready-for-agent`          | `ready-for-agent` | 信息完整，可交给自主代理处理 |
| `ready-for-human`          | `ready-for-human` | 需要人工实现                 |
| `wontfix`                  | `wontfix`         | 不计划处理                   |

技能提到标准角色时，使用表格中对应的本仓库标签。

若仓库以后采用其他标签名称，只修改右侧“本仓库标签”列。
